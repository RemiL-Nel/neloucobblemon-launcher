Comment installer ↓

Installer en 4 étapes

Pas besoin d'installer les mods toi-même : le launcher s'occupe de tout, et des mises à jour aussi.

Télécharge

Clique sur Télécharger le launcher et récupère NelouCobblemon-Setup.exe.

Installe

Lance le fichier et suis l'installation. Le launcher s'ouvre tout seul à la fin.

Connecte-toi

Connecte ton compte Microsoft, celui avec lequel tu as acheté Minecraft Java Edition.

Clique sur JOUER

Le premier lancement télécharge le modpack (environ 1,5 Go), puis tu arrives directement sur le serveur.

Windows peut afficher « Windows a protégé votre ordinateur » : le launcher n'est pas signé par un éditeur payant, c'est normal pour un petit serveur. Clique sur Informations complémentaires puis Exécuter quand même.
